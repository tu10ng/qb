**直接输出结构化结果，不要先写分析。**

这是把人写的东西结构化，不是替人写。铁律：

1. **命令逐字照抄原文**：不改写、不优化、不补参数、不合并不相干的命令。
2. 原文里随环境变化的取值（IP、主机名、端口、路径、卡号、版本号、并行度、网卡名、内存长度等）**提取为参数**：命令里写 `{{参数名}}`，参数名大写下划线（如 PREFILL_IP），value 填原文取值。**参数替换回去后，命令必须与原文逐字一致**；做不到一致就不要提取，整条照抄。
3. 同一个字面值在不同位置含义不同（例如同一个 IP 既是本机地址又是 proxy 地址）时，拆成不同的参数，不要合并。
4. 原文的提醒、坑、注意事项**不能丢**：跟某一步相关的写进该步 `why` 或 `expect`；独立成条的写进 `lessons`（症状 + 修法）。
5. 每一步的 `source` 照抄原文里对应的那一小段（几行就够）。
6. 原文没有的步骤**不要加**。你觉得缺了什么，写进 `gaps`，别自己编命令。
7. `gaps` 写原文没说清、需要人确认的地方（比如"没说两台是否都要设"）。
